# 「我们之间」双人使用手册

更新日期：2026 年 10 月 9 日

## 访问网站

网站地址请向部署管理员获取。可直接分享这份 [HTML 手册](我们之间-双人使用手册.html)。

网站使用 Cloudflare Workers 托管。进入网站需要输入各自单独的成员链接码；ChatGPT 登录账号不会代替链接码。丈夫和妻子各用自己的码，不能互换。链接码是私密凭证，请通过双方认可的私密方式分别交给本人，不要放进聊天截图、公开文档、URL 或共享 Skill。

链接码分别保存在部署管理员设备上的私密目录 `.local-members/partner-husband.json` 和 `.local-members/partner-wife.json`。这两个文件不应发布或写入本手册。若文件不可用，应由管理员通过安全渠道重新配置或轮换，不要把旧码复制进手册。

首次进入网站时，在成员连接框输入自己的链接码。浏览器只在当前会话中保存登录状态；退出网站或关闭会话后可能需要重新输入。另一位伴侣仍需通过自己的成员码进入。Cloudflare Workers 地址本身没有 ChatGPT 账号白名单；若将来增加 Cloudflare Access 等外层访问控制，还需把双方加入该访问范围。

## 本地 Skill 与云端 Therapist 如何配合

每个人在自己的 Codex 中安装「本地 Therapist Assistant」Skill。它先私下倾听，帮助本人梳理观察、理解、感受和希望讨论的问题，再协助写出完整表达。草稿和本地私聊不会因为安装 Skill 自动上传。

准备提交时，本地 Agent 必须展示完整原文、说明另一方也会看到，并取得本人对这个准确版本的明确确认。确认后正式内容才进入双方共同空间。云端 AI Therapist 读取双方正式表达并给出共同回复；正式表达和 Therapist 回复对双方可见。

一次只处理一个当前议题。网站侧栏显示当前话题的自动共识摘要；它是可修正的归纳，不等于双方正式认可。只有双方明确认可同一准确结论，才能记为正式共识。已经 settled 的议题之后只引用共同结论，不重新争论；若要重开，必须双方同意同一个重开请求。后来发生的履约问题作为新的独立议题讨论。

每条正式消息带有 UUID。客户端可按上次 UUID 增量同步，也可全量获取历史；正式记录以文件保存在各自的本地同步目录。私人草稿不应放进同步目录。

## 用一句话请求安装 Skill

在 Codex 或支持 Skills 的 ChatGPT 中，复制并发送下面这句话：

> 请从 GitHub 仓库 `callzhang/family-therapist` 读取 `skills/local-therapist-assistant`，将它安装为当前环境可复用的 Skill；安装后核对 `SKILL.md`、`references/method.md` 和 `references/initialization.md` 均已就位，如果 Skills 功能或安装工具不可用，请说明缺少的条件并停止，不要只在本次对话中遵循，也不要声称已安装。

安装者需要能访问该 GitHub 仓库。ChatGPT 只有在账号/工作区已提供 Skills 功能时，才能通过 Skills 界面创建或安装可复用 Skill；ChatGPT 里的 Skill 安装也不会自动安装到本机 Codex。ChatGPT 的 Skills 功能可用范围与工作区设置有关，参见 [OpenAI 的 ChatGPT Skills 说明](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)。

即使 Skill 已安装，也只代表本地沟通规则可复用。它不会自动连上网站、启用每小时同步或 heartbeat，也不会替用户发送消息；这些能力仍需在各自的 Codex 上配置并验证本地客户端和私密连接。

## 隐私、费用与边界

本地 Agent 负责私下整理和本人确认；云端只处理正式提交的共同空间内容。不要提交希望永久保密、不愿让伴侣或 Therapist 看见的信息。

AI Therapist 是 AI 服务，不是真实持牌心理治疗师，也不能替代专业诊断、医疗建议或紧急危机服务。若存在现实人身危险，请优先联系当地紧急服务或可信任的专业人士。

打开网站本身不按访问次数收费。Cloudflare Workers、D1 和 R2 有免费额度；若 Cloudflare 账号使用付费套餐，可能产生账号级费用。每次云端 Therapist 模型调用会产生模型 API 用量费用，主要随输入上下文和输出 token 数变化。实际账单需以对应服务商账户用量页面为准；本手册不包含 API 密钥或余额信息。

## 联系与排错

- 网站打不开：向部署管理员确认当前地址，并检查网络。
- 链接码无效：确认使用了自己对应的码；不要把码发到公开群或提交到 GitHub。
- Codex 没识别 Skill：确认 `local-therapist-assistant/SKILL.md` 已安装到本机的技能目录，然后重新打开 Codex 或开始新对话。
- Skill 已安装但不能同步：这是预期的分层行为，Skill 安装不会自动配置私密 API 客户端；需要管理员为该成员配置本地连接和客户端。
