# Local Skill release and update

Approved scope: each authenticated sync returns a cloud Skill release notice. The local assistant checks and automatically installs that release through technical validation. No semantic rule governance or bilateral upgrade approval. Conversation messages are never treated as Skill release contents.

Use one deterministic versioned JSON bundle of the three canonical local Skill Markdown files, with a SHA-256 digest over canonical bundle contents. Generate the bundle from source at build time and check it in for auditable release identity. Private authenticated GET /api/skill/release returns this same immutable bundle. GET /api/updates includes release metadata separately from the message list/cursor. The local client fetches the bundle through its fixed-origin authenticated request helper and verifies the announced version/hash, safe exact relative file names, UTF-8 content limits, and no executable payload.

Install the bundle into a private version directory under explicitly configured absolute Skill directory, publish a small current-release pointer atomically after all files are fsynced, and have the installed entry point resolve the current version. Personal state/drafts/tokens remain outside this directory. Preserve earlier release for interrupted-update recovery; no deletion or automatic global installation in this slice. Require safe non-symlink owner-private directories. Never derive a download URL/path from a conversation record. Version equality/digest identity is used; no lexicographic version ordering.

Integrate an explicit sync-and-update CLI accepting Skill install directory as an extra configured argument; preserve existing message-only sync when no installation directory is configured. Skill initialization instructions and local-client operations document use the combined command for hourly heartbeat and entry checks. Tests cover identical-version no-op, changed bundle atomic publication, hash mismatch, partial/crash recovery, unsafe paths/symlinks, private-state preservation, notice retry without cursor loss, and no semantic evaluation. No live provider, deployment, scheduled job, credential reading, or global installation.
