# 本地 Therapist Assistant：当前交付与运行边界

本地 Assistant 的可复用行为规范已写入 [Skill](../../skills/local-therapist-assistant/SKILL.md)，并包含整理方法和初始化/议题操作参考。它指导本地 Codex 先倾听、按需追问、帮助本人形成完整且可编辑的表达，并要求逐字版本确认后才可提交。它不是客户端或已安装的设备软件。

## 已交付

- 私人梳理与正式表达分开；私人草稿和原始本地聊天不上传。
- 正式表达提交前展示全文，说明对方可见；任何文字变化都要求重新确认。
- 双方各自的 Codex Agent 共用一个云端 Therapist；回复与正式内容双方可见。
- 只保留 pending、active、settled 三种议题状态，同一时间至多一个 active。Settled 议题引用共同结论，后续新事件另立议题；重开、切换和结案均遵守双边同意规则。
- 离线或收据不明时保留原草稿与不确定状态，不假报送达，不盲目重发。
- heartbeat 初始化的设计是检查并复用匹配的现有 Codex heartbeat；仅在缺失时创建，之后读回状态。任务静默时不打扰，也不得替本人发送、确认或批准重开。
- 共享 Skill 更新只负责技术来源和完整性边界，不审查语义、不代替双方批准；个人状态与进行中的确认内容独立保留。

## 尚未具备的运行依赖

截至本交付，云端正式消息 API、已验证的实际端点、成员认证配置、本地同步客户端和系统升级包协议均未交付。Codex heartbeat 可以按设计由原生自动化能力管理，但没有真实可用的认证传输配置时，本次不创建任务、不启动同步，也不宣称初始化完成。云端 Therapist Skill 源文件存在，也不表示云端调用已接通。

因此，本次完成的是指令源与操作边界。仍需后续实现并验证传输/API、双方身份和凭证流程、本地游标及落盘客户端、heartbeat 创建/复用后的实际读回，以及自动升级器。在这些证据出现前，助手只能协助本地梳理和草拟，不能将正式文字发送给共同空间。
